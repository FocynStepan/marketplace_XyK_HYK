# Універсальний Маркетплейс ХуК_НУК

**Версія:** 1.0.0 (Pre-Alpha)
**Статус:** В активній розробці (In Progress)

Платформа електронної комерції (аналог Prom/Rozetka), розроблена для об'єднання локальних продавців та покупців в єдину зручну екосистему. Проєкт включає повний цикл розробки: від збору вимог та проєктування UI/UX до реалізації бекенду та клієнтської частини.
